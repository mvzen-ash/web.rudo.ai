How licensing works

Pay once, activate once, run forever on that machine

1. Checkout

Pick a tier, pay through our checkout provider. No account required beyond an email address.

2. Key issued

On confirmed payment, a signed one-time activation key is generated and emailed to you alongside the app download.

3. Install & activate

Install the desktop app, paste the key on first launch. Activation is verified once online, then Rudo.ai runs fully offline-capable from there.

4. You own the install

No subscription to cancel. Updates are optional pulls, not forced check-ins.
